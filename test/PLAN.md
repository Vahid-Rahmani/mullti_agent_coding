# PLAN.md — برنامه مدیریت هزینه‌های روزمره

## هدف (Objective)
ساخت یک برنامه ساده پایتون برای مدیریت هزینه‌های روزمره که امکان:
- افزودن هزینه (add)
- مشاهده لیست هزینه‌ها (list)
- محاسبه مجموع خرج‌ها (total)

را فراهم کند. داده‌ها در یک فایل JSON ذخیره می‌شوند و برای هر بخش، تست واحد نوشته می‌شود.

## Scope (محدوده)
در این نسخه، پروژه در پوشه `test/` ساخته می‌شود:
- ماژول اصلی `expense_manager.py` — شامل کلاس `ExpenseManager`
- ذخیره/بارگذاری JSON
- رابط کاربری ساده خط فرمان (CLI) برای افزودن/لیست/مجموع
- تست‌های واحد (Unit Tests) با `unittest` یا `pytest` بدون وابستگی خارجی

## خارج از محدوده (Out of Scope)
- احراز هویت / چند کاربر
- دسته‌بندی پیشرفته / بودجه / نمودار
- رابط وب یا GUI
- دیتابیس غیر از JSON

## ساختار پوشه پروژه
```
test/
├── expense_manager.py      # کلاس ExpenseManager + ذخیره/بارگذاری JSON
├── app.py / cli.py          # رابط خط فرمان
├── data/expenses.json       # فایل داده (ذخیره‌شده در زمان اجرا)
├── tests/
│   ├── __init__.py
│   ├── test_expense_manager.py
│   └── test_cli.py
├── PLAN.md
└── TASKS.json
```

## Epics (حماسه‌ها / فازها)
1. **Epic 1 — هسته و ذخیره‌سازی (Core + Storage)**
   پیاده‌سازی `ExpenseManager` و لایه JSON.
2. **Epic 2 — رابط خط فرمان (CLI):**
   دستورهای add / list / total.
3. **Epic 3 — تست‌های واحد (Tests):** تست‌های هسته و CLI.

## Phases (فازها / ترتیب اجرا)
- **Phase A:** ساختار اولیه پروژه + فایل `expense_manager.py`.
- **Phase B:** CLI در `app.py`.
- **Phase C:** تست‌های واحد برای هسته و CLI + اجرا و تأیید.
- **Phase D:** بررسی نهایی (review) و مستندسازی short README.

## قوانین و نکات
- این پروژه یک پروژه مستقل پایتون است (استقلالی از پوشه کنترل‌پلن)، داخل `test/`.
- هیچ رازی commit نمی‌شود؛ فایل JSON داده نمونه است و باید در `.gitignore` یا نمونه (sample) باشد.
- تست‌ها با `python -m unittest` اجرا می‌شوند (بدون نیاز به pytest برای سادگی).
- تمام agentها free model دارند؛ تست‌ها باید سریع و بدون نیاز به شبکه اجرا شوند.

## معیار موفقیت (Definition of Done)
- `expense_manager.py` موجود است و افزودن/لیست/مجموع را از طریق JSON انجام می‌دهد.
- `app.py` قادر است از CLI add / list / total را اجرا کند.
- تمام تست‌های واحد سبز هستند (`python -m unittest` exit 0).
