# knowledge/

Project memory for the swarm. Consult this before planning or reviewing.

- `adr/` — architecture decision records (one file per decision).
- `lessons/` — lessons learned and recurring failure patterns.
- `metrics.jsonl` — per-session metrics (tokens, success, interventions).
- `index.jsonl` — vector index produced by `scripts/index-memory.mjs` (not committed).
