- **Main purpose:** Tutorials and implementations for GenAI agent techniques,
  from basic conversational bots to complex multi-agent systems.
- **Important directories/files:** per-agent tutorial notebooks; README catalog
  of agents (beginner → framework → educational → business → creative); related
  repos for RAG, production agents, and prompt-engineering techniques.

  (planner/workers, supervisor, router, reflection), planning, memory, tool
  usage, routing, reflection, evaluation, RAG/knowledge patterns.
- **Useful prompts/skills:** agent-role framing and workflow-decomposition
  prompts (concepts only — see license restrictions).
- **Useful workflow patterns:** planner/workers/reviewer fan-out/fan-in;
  supervisor; router; reflection with bounded review loops.
- **Useful architectural patterns:** separation of agent identity from the
  orchestration graph; explicit handoff contracts between steps.
- **MultiAgentCoding integration:** conceptual grounding for the existing
  workflow templates (planner-workers-reviewer, supervisor, router, reflection)
  and the `agent-workflow-planner` prompt profile.
